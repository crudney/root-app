Root privacy policy

Last updated: October 24, 2026

Root is a personal, self-hosted application used only by its owner. It is not offered to the public.

What Root accesses

With the owner's permission, Root reads the owner's own Gmail accounts using Google's read-only permission (gmail.readonly). It shows message senders, subjects, previews and message text on a dashboard that runs on the owner's home computer.

What Root does not do

  • It does not send, delete, label or change any email.
  • It does not share, sell or transfer any data to anyone.
  • It does not use the data for advertising, profiling, or training AI models.
  • It does not store email content on any server other than the owner's own computer.

Storage and security

Sign-in tokens and short-lived caches are stored only on the owner's home computer. The dashboard is reachable only from that computer.

Google API Services

Root's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
